### 🧠 [Equity Crash Prediction](https://github.com/addicteduser04/Detection-of-extreme-market-events-using-Machine-Learning)

**Machine Learning for Rare Financial Events**

Built a classification pipeline to detect extreme equity-market events using market, volatility, and macroeconomic features.

* Logistic Regression, Random Forest & XGBoost
* 26 years of QQQ market history
* 5,294 walk-forward out-of-sample predictions
* Random Forest achieved **0.063 PR-AUC**
* Precision-recall evaluation for highly imbalanced events

**Stack:** Python · Pandas · NumPy · scikit-learn · XGBoost
